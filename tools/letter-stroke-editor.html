Letter Stroke Editor

This is how the drawing game teaches each letter. Play shows the demo the child sees first (an orange pen draws each stroke in order). The grey road with the green numbered dot is what the child traces afterwards. Click any letter to fix its strokes: drag a point, drag on a line to add one, reverse or reorder strokes. Edits save in this browser. When you are done, copy the changes and paste them back to me.

Drag a point to move it. Drag along a line to add a point. Select a point to nudge it with the arrow keys or delete it.
